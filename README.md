# Shuten Shell
### ShuTerm? Shellten?
A bunch of dotfiles to theme your Z-shell around Shuten Douji from FGO.

The point was to make my terminal look pretty when I use it. The fastfetch config reflects this; it's kept minimal to look good, not necessarily useful.

It can also show some minimal git info when you're in an initialized folder.

The font I use is SFMono NerdFont Ligaturized. Use whatever NerdFont you already have, I'm not bundling the font here.

My personal config has zsh-patina and zsh-autosuggestions installed via homebrew, but I've left them out so you can decide what you want to have.

# Installation

Rename 'shuten.zshrc' to '.zshrc' and replace your .zshrc, wherever it is. Make a backup of your original .zshrc before doing so

Replace your fastfetch config.jsonc with mine. Backup your config if you want to revert to it later. Place 'shuten-logo.txt' next to the config.jsonc
